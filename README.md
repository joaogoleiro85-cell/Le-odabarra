# Leão da Barra — projeto Android

Aplicativo inicial para Android, feito com Kotlin e Jetpack Compose, em tema preto e vermelho.

## Abrir
1. Instale o Android Studio em um computador.
2. Abra a pasta `LeaoDaBarraAndroid`.
3. Aguarde a sincronização do Gradle.
4. Execute em um emulador Android ou aparelho conectado.

## Estado desta versão
- Navegação funcional entre Início, Notícias, Jogos, Números e Elenco.
- Layout adaptado para Android.
- Conteúdo demonstrativo claramente identificado.
- Ainda não consulta notícias, resultados ou estatísticas em tempo real.
- Ainda não é um APK assinado/pronto para publicação.
